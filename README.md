## 📖 نبذة عن التطبيق

صُمم تطبيق **صلاتي (Salati)** ليكون رفيقك اليومي في المحافظة على الصلاة والأذكار والسنن النبوية الشريفة. بُني التطبيق بأحدث تقنيات أندرويد المعاصرة (**Jetpack Compose & Material 3**) لتقديم تجربة استخدام فائقة السلاسة والسرعة، مع احترام كامل لخصوصية المستخدم وخلو تام من أي إعلانات أو متتبعات تجارية.

---

## ✨ المميزات الرئيسية

### 🕒 ١. مواقيت الصلاة والتقويم الهجري الدقيق
* حساب فلكي دقيق لمواقيت الصلاة الخمس مع شروق الشمس ومنتصف الليل وثلث الليل الأخير.
* **دعم ديناميكي كامل للمناطق الزمنية (IANA Time Zones):** مزامنة فورية للتوقيت الصيفي والشتوي تلقائياً دون أي تضارب أو فرق ساعة.
* **تحديد الموقع التلقائي (GPS):** كشف موقعك بدقة بضغطة زر واحدة واختيار أقرب مدينة مع حفظ الموقع دائماً.
* **بطاقة التوقيت المزدوج (Dual Timezone):** متابعة مواقيت الصلاة لمدينة أخرى (مكة المكرمة، المدينة المنورة، أو أي مدينة في العالم).

### 🔊 ٢. نظام الأذان والتنبيهات المتقدم
* **تشغيل صوتي متواصل في الخلفية:** استمرار صوت الأذان دون انقطاع عند استخدام التطبيقات الأخرى أو التنقل بين البرامج.
* **توجيه الصوت الذكي:** تحويل صوت الأذان تلقائياً إلى سماعات البلوتوث الموصلة دون إجبار الصوت على الخروج من مكبر الهاتف الخارجي.
* **شاشة أذان تفاعلية ملء الشاشة (Full-Screen Adhan):** تصميم إسلامي مهيب يعمل حتى والهاتف مقفل مع إمكانية إيقاف الأذان أو تأجيله.
* تنبيهات الإقامة، وتنبيهات الاستعداد قبل الصلاة برنين مخصص.

### 📱 ٣. الودجت الذكية الواحدة المتجاوبة (Smart Responsive Widget)
* **ودجت واحدة تفاعلية على الشاشة الرئيسية تغنيك عن أي تطبيقات أخرى:**
  * **الحجم القياسي (٢×٤):** يعرض اسم المدينة، التاريخ الهجري، كارت الصلاة القادمة بالعد التنازلي الحي للثواني، ومواقيت الصلوات الخمس مع دوائر تعليم الفروض.
  * **الحجم الموسع (٣×٤ أو ٤×٤):** بمجرد سحب الودجت للأسفل، تظهر تلقائياً **السنن والنوافل الـ ٨ كاملة** مع عداد الإنجاز وإمكانية تعليمها مباشرة من الشاشة الخارجية.
* **ألوان علامات صح متجاوبة ديناميكياً:** يتكيف لون دوائر التحديد تلقائياً مع الثيم المختار للتطبيق بدلاً من اللون الأخضر الثابت.

### 📊 ٤. متابعة الصلوات والسنن والنوافل
* متابعة الصلوات المفروضة الخمس (الفجر، الظهر، العصر، المغرب، العشاء).
* متابعة السنن الرواتب والنوافل الثمانية:
  1. سنة الفجر القبلية
  2. صلاة الضحى (صلاة الأوابين)
  3. سنة الظهر القبلية (٤ ركعات)
  4. سنة الظهر البعدية (ركعتان)
  5. سنة العصر القبلية
  6. سنة المغرب البعدية
  7. سنة العشاء البعدية
  8. قيام الليل والشفع والوتر
* إحصائيات التزام تفصيلية، وحساب سلسلة المحافظة المستمرة (**Streak Tracker**)، وتقويم شهري يوضح الأيام المكتملة.

### 🤲 ٥. حصن المسلم والمسبحة الصوتية
* **تلاوة صوتية كاملة ومتواصلة لأذكار الصباح والمساء الـ ٤١ بصوت عذب نقي.**
* مشغل صوتي تفاعلي للتقديم والتأخير والاستماع أثناء القفل.
* سبحة إلكترونية رقمية ذكية مع استجابة اهتزازية لمسية (**Haptic Feedback**) للعدّ دون النظر للشاشة.

### 🧭 ٦. بوصلة القبلة الدقيقة ثلاثية الأبعاد (3D Qibla Compass)
* تحديد اتجاه الكعبة المشرفة بدقة متناهية بالدرجات والاتجاهات الجغرافية بالاعتماد على مستشعرات البوصلة والمجال المغناطيسي للهاتف.

### 📖 ٧. ختمة وتلاوة القرآن الكريم
* متتبع ذكي للورد اليومي وختمات القرآن الكريم (٦٠٤ صفحة).
* إحصائيات عدد الصفحات والختمات المنجزة مدى الحياة.

### 🎨 ٨. استوديو الثيمات وتخصيص المظهر
* **٤ ثيمات مسبقة ذات طابع إسلامي راقٍ:**
  - 🌿 **الزمرد الملكي** (Royal Emerald)
  - 🕋 **الكعبة المشرفة** (Holy Kaaba - سواد وذهب خالص)
  - 🕌 **المسجد النبوي** (Madinah Green)
  - 🌊 **الفيروز الأندلسي** (Andalusian Turquoise)
* **استوديو الثيم الخاص (Custom Theme Studio):** حرية كاملة لاختيار ألوان الخلفية والكروت والإضاءات الذهبية والأساسية.
* **التحكم في حجم الخطوط (Font Size Scaling):** ٤ أحجام مختلفة (صغير ٨٥٪، عادي ١٠٠٪، كبير ١١٥٪، كبير جداً ١٣٠٪) مع معاينة فورية لراحة العين.

### 🛡️ ٩. النسخ الاحتياطي والأمان التام
* **تصدير واسترجاع فوري (JSON Backup):** حفظ واسترجاع كافة سجلات صلواتك بنقرة زر عند تغيير الهاتف أو إعادة التثبيت.
* **نظام التحديث التلقائي:** فحص وتنزيل التحديثات الرسمية الجديدة مباشرة من داخل التطبيق عبر GitHub Releases.
* **نسخة رسمية موقعة (Release Signed):** حماية كاملة ومنع لرسائل فحص التثبيت وضمان قبول التحديثات القادمة بسلاسة.

## 🛠️ البنية التقنية (Tech Stack)

* **لغة البرمجة:** Kotlin 2.0+
* **واجهة المستخدم:** Jetpack Compose (Material Design 3)
* **معمارية المشروع:** Clean Architecture + Unidirectional Data Flow (MVI/MVVM)
* **التزامن وإدارة البيانات:** Kotlin Coroutines & StateFlow
* **الودجات:** Android AppWidgetProvider + Dynamic Vector Canvas Bitmaps
* **الصوتيات والخدمات:** Android Foreground Service (Media Playback Audio Attributes)
* **التشفير والتخزين:** KotlinX Serialization + Local Encrypted Storage
